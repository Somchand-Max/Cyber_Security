# Contributing to Cyber_Security

Thank you for your interest in contributing to this cybersecurity knowledge base and engineering documentation portfolio.

## 1. Ethical & Responsible Research Policy

This repository is maintained by **Som Choudhary** for academic study, defensive security engineering, CTF analysis, and knowledge sharing. All research and tools documented herein are designed strictly for authorized, defensive testing and security auditing.

By contributing to or utilizing materials from this repository, you agree to:
- Comply with all applicable computer crime and cybersecurity laws (including the Information Technology Act, CFAA, and international equivalents).
- Engage strictly in authorized testing against targets where you have explicit, documented consent from the system owner.
- Never use these materials for malicious attacks, unauthorized scanning, denial of service, credential stuffing, or surveillance.

## 2. Documentation Standards

When submitting issues or pull requests:
- **Accuracy First:** Statements must be verified against actual code, RFC specifications, or reproducible lab environments.
- **Evidence Labeling:** Clearly tag content as `IMPLEMENTED` (source-verified), `TESTED` (test-backed), or `RESEARCH` (theoretical / future study).
- **Sanitization Invariant:** Never submit real API keys, production tokens, unhashed passwords, private phone numbers, or private user data. All examples must use sanitized placeholder data (e.g., `+919876543210`, `example.com`, `sk-placeholder-key`).
- **Tone:** Maintain professional, objective, and transparent technical English. Avoid exaggerated terms like "unhackable" or "military grade".
